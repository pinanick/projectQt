# 5. Интерфейс PyQt6

## Основные понятия

QApplication управляет приложением и циклом событий; QWidget — базовый класс виджетов; QMainWindow — окно с центральным виджетом, меню и строкой состояния; QDialog — диалог. Сигнал сообщает о событии, connect связывает его с вызываемым объектом (слотом). Скобки после имени метода в connect не ставятся: передаётся сам метод, а не результат его немедленного вызова.

uic.loadUi(path, self) читает XML-макет и заполняет существующий экземпляр виджетами. Имена объектов из Qt Designer становятся доступными в Python, например self.generateButton. Переименование объекта в XML без исправления Python приведёт к ошибке обращения к атрибуту.

## XML-макеты ui/designer/

Формат .ui — декларативный XML, не исполняемый Python. Каждый открывающий тег имеет закрывающий тег или сокращённую форму />. Вложенность определяет структуру интерфейса. Порядок элементов layout задаёт расположение; имя объекта используется в Python.

| XML-конструкция | Что означает |
|---|---|
| <?xml ...?> | Версия XML и кодировка файла UTF-8. |
| ui version="4.0" | Формат Qt Designer, а не версия PyQt. |
| class | Имя формы. |
| widget class / name | Тип виджета и его objectName. |
| property name | Настраиваемое свойство объекта. |
| rect / x / y / width / height | Начальная геометрия; layout и оконный менеджер могут изменить её. |
| string / number / bool / enum / set | Представление значения свойства соответствующего типа. |
| layout | Менеджер размещения дочерних элементов. |
| item | Элемент layout; у QFormLayout row и column обозначают позицию. |
| column | Описание столбца QTableWidget и его заголовка. |
| spacer | Свободное пространство между элементами. |
| attribute name="title" | Заголовок вкладки. |
| action / addaction | Создание QAction и добавление действия в меню. |
| resources / connections | Ресурсы и связи, заданные в Designer; в текущих макетах пусты, связи подключаются Python-кодом. |

### Назначение пяти форм

- [main_window.ui](../ui/designer/main_window.ui): QMainWindow, центральный QWidget, вертикальный layout, горизонтальная панель из трёх кнопок, QTabWidget с заглушками, меню Файл с тремя QAction и QStatusBar.
- [dashboard_page.ui](../ui/designer/dashboard_page.ui): три QLabel со счётчиками, заголовок последних событий, таблица из четырёх столбцов и предупреждение об учебных данных.
- [events_page.ui](../ui/designer/events_page.ui): заголовок, описание, QLineEdit search, QComboBox kind, таблица из пяти столбцов, QLabel counter. placeholderText — подсказка для пустого поля, не введённый текст.
- [incidents_page.ui](../ui/designer/incidents_page.ui): таблица из шести столбцов; QFormLayout с info, status и notes; кнопка save. wordWrap разрешает перенос текста; maximumHeight ограничивает высоту заметок.
- [rules_dialog.ui](../ui/designer/rules_dialog.ui): описание, форма из двух QSpinBox с minimum, maximum, value и suffix для секунд, QDialogButtonBox со стандартными кнопками Save и Cancel.

Это справочник по всем видам XML-строк и объектам пяти форм, а не отдельная таблица с номером каждой строки XML. Пустые строки Python не выполняют инструкций; комментарии, скобки и продолжения выражений объяснены вместе с соответствующими блоками.
