## Вопросы и ограничения

- CSV — не Excel-файл XLSX; это текстовый формат с разделителями. Пример находится в [examples/sample_events.csv](../examples/sample_events.csv).
- Почему import работает с временным списком? Чтобы не начать запись частично проверенного файла.
- Почему нет ID в CSV? При повторном импорте SQLite назначает новые ID. Дубликаты импортированных событий не исключаются.
- Почему не json? CSV подходит для плоской таблицы из фиксированных колонок.
- Почему strptime не гарантирует строго нормализованный timestamp? Некоторые директивы допускают неполную ширину чисел, а код не сохраняет результат разбора обратно через isoformat. Это ограничение для последующей сортировки и fromisoformat.
- Безопасность CSV: экспорт сохраняет текстовые значения как есть, не нейтрализуя формулы электронных таблиц. Не следует открывать непроверенные CSV в редакторах с автоматическим вычислением формул.
- Файлы могут быть перезаписаны; экспорт не является атомарной записью с временным файлом.
- Пустой IP и некорректный IP — разные вещи: проверяется только непустота.

Пустые строки ничего не выполняют. Многострочные выражения объяснены по связанным диапазонам.
