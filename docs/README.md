## Как пользоваться

- Сначала прочитай архитектуру и научись объяснять путь данных через приложение.
- Затем разбирай исходники по одному файлу. Номер строки относится к файлу в репозитории на момент подготовки документации.
- Для каждой строки отвечай на четыре вопроса: **что делает; зачем нужна; что изменится без неё; от чего зависит**.
- После чтения закрывай документацию и пересказывай алгоритм своими словами.
- Если код изменился, сверяй документацию с актуальной веткой.

## Границы проекта

CyberLab — учебное настольное приложение для анализа искусственных событий входа. Оно демонстрирует отдельные принципы SOC: сбор журнала, простые правила обнаружения, регистрацию инцидентов и их ручную обработку. Это не промышленная SIEM, не средство защиты реальной инфраструктуры и не источник телеметрии ОС.
