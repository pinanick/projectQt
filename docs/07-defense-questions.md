# 7. Вопросы на защите

## Краткое представление проекта

CyberLab — локальное учебное приложение на Python и PyQt6 для анализа записей о входе. Оно генерирует искусственные события или импортирует их из CSV, хранит историю в SQLite, находит подозрительные последовательности по двум детерминированным правилам и позволяет вручную вести карточки инцидентов. В проекте разделены интерфейс, обработка событий, хранение и файловые операции.

## Базовый уровень

| Вопрос | Ответ |
|---|---|
| Что такое SOC? | Security Operations Center — команда и процессы мониторинга, анализа и реагирования на события безопасности. CyberLab демонстрирует отдельные принципы такой работы. |
| Событие и инцидент — одно и то же? | Нет. Событие — запись о действии, инцидент в CyberLab — сохранённый результат совпадения с правилом. |
| Это антивирус? | Нет. Программа не сканирует файлы и не блокирует угрозы. |
| Это ML? | Нет. Используются фиксированные правила и пороги, обучение отсутствует. |
| Почему Python? | Стандартная библиотека содержит SQLite, CSV, datetime и структуры данных; PyQt6 позволяет реализовать настольный интерфейс. |
| Почему SQLite? | Локальная файловая БД, простой запуск и сохранение данных между сеансами. |
| Почему PyQt6? | Виджеты, готовая событийная модель и поддержка XML-макетов Qt Designer. |
| Откуда берутся события? | Из локального генератора или импортированного CSV. |
| Работает ли приложение в реальном времени? | Нет. Анализ запускается вручную по сохранённой истории. |
| Сколько событий добавляет генерация по умолчанию? | 49: 40 фоновых и 9 демонстрационных записей. |
| Когда генерируются начальные данные? | При запуске, если таблица events пуста. |
| Что происходит после закрытия окна? | Цикл Qt завершается, finally закрывает соединение; ранее зафиксированные данные остаются в SQLite. |

## Python

| Вопрос | Ответ |
|---|---|
| Что такое self? | Ссылка на экземпляр, через неё доступны его поля и методы. |
| Что такое __init__? | Метод инициализации уже созданного экземпляра. |
| Что делает super()? | Даёт доступ к методам следующего класса в порядке разрешения методов; здесь вызывается конструктор базового виджета. |
| Зачем __name__ == "__main__"? | Отличает непосредственный запуск файла от его импорта. |
| Что значит параметр со значением по умолчанию? | Если аргумент не передан, используется указанное при определении функции значение. |
| Чем list отличается от tuple? | Список изменяемый, кортеж — неизменяемая последовательность. |
| Что такое dict? | Отображение хешируемого ключа в значение. |
| Почему кортеж может быть ключом dict? | Кортеж хешируем, если все его элементы хешируемы. Здесь обе части ключа — строки. |
| Что такое comprehension? | Выражение построения коллекции из перебора и необязательного условия. |
| Что делает enumerate? | Возвращает пары индекс–элемент; начало индекса можно изменить через start. |
| Что делает zip? | Объединяет элементы нескольких последовательностей в кортежи; по умолчанию останавливается на самой короткой. |
| Что такое lambda? | Короткая функция с одним выражением; используется как ключ сортировки. |
| Чем sorted отличается от list.sort? | sorted возвращает новый список, list.sort изменяет исходный и возвращает None. |
| Что такое *_? | Сбор лишних позиционных аргументов в кортеж с именем _, которое по соглашению не используется. |
| Что делает casefold? | Приводит текст к форме для регистронезависимого сравнения, в общем случае полнее lower. |
| Что делает strip? | Удаляет пробельные символы с краёв строки. |
| Что значит dict.get(key, default)? | Возвращает значение ключа или default при его отсутствии. |
| Что означает is None? | Проверяет идентичность специальному объекту None, а не ложность значения. |
| Как работает try/except/finally? | try выполняет инструкции; except обрабатывает подходящее исключение; finally выполняется при выходе из try. |
| Что делает with? | Использует протокол контекстного менеджера, выполняющий вход и выход из контекста. Для файла это управление закрытием, для соединения SQLite — транзакцией. |

## Алгоритмы

| Вопрос | Ответ |
|---|---|
| Почему два детектора? | Они анализируют разные признаки: частые ошибки одного источника и успешный вход после ошибок одной пары IP–пользователь. |
| Почему defaultdict(list)? | Упрощает группировку: отдельный список создаётся при первом обращении по отсутствующему ключу. |
| Почему deque? | Добавление справа и удаление слева выполняются за O(1); это естественная структура скользящего окна. |
| Зачем datetime? | Строки удобны для хранения, но вычислять интервалы удобно по объектам времени. |
| Что означает total_seconds? | Полная длительность timedelta в секундах, включая дни и дробную часть. |
| Почему используется while, а не if при очистке окна? | За один шаг могут устареть сразу несколько записей; нужно удалить все неподходящие. |
| Зачем второй ключ id при сортировке? | Для определённого порядка при совпадающем timestamp. |
| Почему active? | Чтобы не создавать отдельную тревогу на каждое последующее событие уже отмеченной последовательности. Есть ограничение при повторном достижении порога, см. раздел 03. |
| Зачем clear после успешного входа? | Последующие ошибки рассматриваются как новая последовательность для второго детектора. |
| Какова сложность? | Сортировка O(n log n) в худшем случае, обработка очередей O(n), дополнительная память O(n). |
| Почему совпадение с правилом не доказывает атаку? | У обычной активности могут быть те же признаки; алгоритм не знает намерений и не проверяет подлинность источника. |

## SQLite

| Вопрос | Ответ |
|---|---|
| Чем отличаются PRIMARY KEY и FOREIGN KEY? | Первый идентифицирует запись собственной таблицы, второй связывает значение с ключом другой таблицы. |
| Зачем AUTOINCREMENT? | Для последовательной выдачи ROWID без повторного использования ранее выданных значений после удаления. |
| Почему используется ? в SQL? | Для передачи значений отдельно от текста инструкции; это параметризация. |
| Что означает SELECT *? | Выбор всех колонок. |
| Что означает ORDER BY ... DESC? | Сортировка по убыванию. |
| Зачем LIMIT? | Ограничивает число возвращаемых строк. |
| Что делает fetchone()? | Получает одну следующую строку результата либо None, если строки нет. |
| Зачем COALESCE? | Возвращает первое не-NULL значение; в счётчике заменяет NULL на ноль. |
| Что делает INSERT OR IGNORE? | Пропускает некоторые нарушения ограничений, включая конфликт UNIQUE; не заменяет существующие данные. |
| Что делает WHERE? | Ограничивает выборку или изменение строк условием. |
| Что такое транзакция? | Группа операций, изменения которой фиксируются или откатываются. |
| Зачем миграция? | Чтобы старая БД получила новое поле incident_type без удаления существующих записей. |
| Почему UNIQUE не удаляет дубликаты CSV? | Ограничение находится в incidents, а не events. |

| Вопрос | Ответ |
|---|---|
| Зачем QApplication до QWidget? | Qt требует инициализацию объекта приложения перед созданием графических виджетов. |
| Что делает app.exec()? | Запускает цикл обработки событий. |
| Что такое сигнал? | Уведомление Qt о событии, к которому можно подключить вызываемые объекты. |
| Почему connect(self.analyze), а не connect(self.analyze())? | Первый вариант передаёт метод для будущего вызова, второй вызвал бы его сразу. |
| Зачем uic.loadUi? | Загружает XML-макет и создаёт/настраивает интерфейс экземпляра. |
| Что такое layout? | Менеджер размещения элементов, адаптирующий геометрию к доступному пространству. |
| Что такое QTableWidgetItem? | Объект отдельной ячейки QTableWidget. |
| Зачем blockSignals? | Временно подавляет сигналы при программном обновлении таблицы. |
| Что значит currentData? | Скрытое значение выбранного пункта комбобокса, не отображаемая подпись. |
| Что делает QDialog.exec()? | Открывает модальный диалог с собственным циклом обработки событий и возвращает результат. |

| Есть ли потоки? | Нет. Анализ и файловые операции выполняются синхронно в GUI-потоке. |
