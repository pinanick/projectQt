# CyberLab — учебный проект на PyQt6

**Назначение:** настольное приложение для учебного анализа событий входа в систему. Проект демонстрирует базовые принципы SOC: журнал событий, обнаружение подозрительной активности, регистрацию инцидентов и ведение заметок.

Программа работает с **искусственными данными** и CSV-файлами. 

## Реализованные функции

1. **Обзор:** количество событий, ошибок входа и инцидентов.
2. **События:** журнал с поиском по пользователю и IP, фильтрация по типу.
3. **Генератор:** создаёт тестовые события, включая подозрительную последовательность.
4. **Анализ:** два простых правила:
   - по умолчанию 5 ошибок входа с одного IP за 60 секунд (порог и интервал можно настроить);
   - успешный вход после 3 ошибок от того же IP для того же пользователя в течение 120 секунд.
5. **Инциденты:** просмотр, смена статуса и комментарий.
6. **Файлы:** импорт и экспорт событий в CSV, простой отчёт TXT через меню «Файл».
7. **SQLite3:** события, инциденты и настройки правила сохраняются после закрытия программы.

## База данных

| Таблица | Назначение |
|---|---|
| `events` | ID, время, пользователь, IP и тип события |
| `incidents` | обнаруженная серия, её тип, времена, статус и комментарий |
| `rules` | порог и временное окно для первого правила |

`Repository` читает и изменяет базу. Функции `detect_failed_logins()` и `detect_success_after_failures()` принимают список событий и **не выполняют SQL-запросов**. Пара `(ip, first_event_id)` в таблице инцидентов уникальна, поэтому повторный анализ не создаёт одинаковые тревоги.


Код разделён на модули для удобства чтения: интерфейс находится в `ui/`, анализ в `core/`, SQLite в `database/`.

## Изменение интерфейса в Qt Designer

В папке `ui/designer/` лежат пять файлов `.ui`:

| Файл | Что изменяется в Qt Designer |
|---|---|
| `main_window.ui` | Главное окно, меню, кнопки, вкладки |
| `dashboard_page.ui` | Надписи и таблица обзора |
| `events_page.ui` | Поиск, фильтр и таблица событий |
| `incidents_page.ui` | Таблица инцидентов и поля расследования |
| `rules_dialog.ui` | Диалог настройки обнаружения |
